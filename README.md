# Warcraft III 玩家监测程序 使用说明

## 1. 程序简介
本程序通过 EasyOCR（深度学习识别）技术实时监测 Warcraft III 游戏画面中的玩家列表，并在检测到目标玩家时发出声音提醒并弹出窗口。

## 2. 环境依赖 & 硬件加速
打包后的程序已内置 EasyOCR 和 PyTorch 环境。

### 2.1 GPU 加速 (推荐)
如果您使用的是 NVIDIA 显卡（如 RTX 50 系列），建议安装最新的 **NVIDIA 驱动程序**。
程序在启动时会自动检测显卡：
- **检测到 GPU**: 识别速度极快，系统资源占用低。
- **未检测到 GPU**: 将自动回退到 CPU 模式，识别速度较慢（约 2-3 秒一次）。

## 3. 安装与使用
1. **安装程序**: 运行 `PlayerMonitor_Setup_v1.0.0.exe` 按照向导完成安装。
2. **管理名单**: 您可以直接在程序界面下方的输入框中添加玩家 ID，点击“添加”即可实时生效并自动保存。
3. **已存名单**: 名单保存在程序安装目录下的 `paid_player_id.txt` 中。
4. **运行监测**: 点击“开始识别”按钮。
5. **游戏设置**: 请确保游戏以**窗口模式**或**无边框窗口模式**运行。

## 4. 常见问题
- **界面模糊**: 程序已适配 DPI 缩放，如果在高分屏上显示异常，请右键属性设置“禁用高 DPI 缩放”。
- **识别不灵敏**: 请确保游戏画面没有被其他窗口大幅度遮挡，且监测区域（左侧中间位置）可见。
